# István Kónya academic website template

A research-first Quarto website template with responsive styling and placeholder content.

## Edit the site

- Update biography and featured papers in `index.qmd`.
- Replace placeholder publications and links in `research.qmd`.
- Update courses in `teaching.qmd` and appointments in `cv.qmd`.
- Add a portrait and replace the `.portrait-placeholder` block with an image.
- Put the PDF CV at `files/konya-cv.pdf`.

## Preview and build

```bash
quarto preview
quarto render
```

The rendered site is written to `dist/`.
